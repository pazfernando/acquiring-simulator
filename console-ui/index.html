Acquiring Simulator console

Operation A · synthetic authorization submission · local development harness

No credential

Local development harness — this is NOT authentication. The token comes from an unsigned, in-memory development stub. No signature, issuer or key is verified, and anyone who can reach this loopback port can obtain the same token. This page is not connected to Keycloak, API Gateway, CloudFront, WAF or AWS. Never use it to represent a real login, a real session or a real payment.

1. Dev stub credential

unsigned · memory only

The console is a public client shape. Here the credential is requested from the local harness (/dev/v1/stub-token) and held only in this module's memory: no localStorage, no sessionStorage, no cookie and no URL parameter. It expires after the harness-configured lifetime and is discarded on refusal or expiry.

Not acquired.

Only the approved C1 fields are sent. The acquirer, merchant and terminal shown here are the trusted demo context served by the harness; the server still refuses any mismatch rather than trusting the body. All identifiers are synthetic.
