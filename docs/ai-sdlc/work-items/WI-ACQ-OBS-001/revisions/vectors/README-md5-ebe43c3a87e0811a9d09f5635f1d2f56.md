## Exact bytes and decoding
hex is authoritative; length/SHA256 identify it. For ACCEPT, expectedDecodedFields is complete independent decoded output and equals logicalFields; extension equals canonical DE48 parsed output. For rejected packets expectedDecodedFields=null: partial authoring fields must NOT be admitted. expectedFirstFailure is the first violated rule using the phase order in P6. Downstream invalidities are not separately counted.
In particular, the intentionally wrong four-digit prefix for length 1000 is NOT a valid LLL encoding. Under the fixed-width walker its first failure is DE49 alphabet after reading the first three prefix bytes; there is no claim that a valid LLL prefix encodes 1000.
