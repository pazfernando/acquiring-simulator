## Recommendation and concrete operational contract
Adopt as candidate one canonical event source with conditional producer/event dedupe and atomic append sourceSequence. Critical transitions include journal/evidence in transaction; best-effort task hooks use same table async and may be lost; ADOT sampled/exported separately. No source event/span changes payment outcome by itself.
Notifier only fans retained source pointers/payload to CURRENT technical subscriptions. At-least-once callback retry can duplicate/lose browser delivery; source HTTP catch-up is recovery. Subscribe routing installed and ACK head/generation BEFORE strong fixed-head catch-up; buffer frames from request, dedup source/producer/hash, ignore old generation. Gap/heartbeat triggers catch-up, no1s HTTP polling. No durable perbrowser queue; disconnected viewers recover retained events or see truncation.
PROPOSED limits: <=50 connections/environment,10 subscriptions each,30min lease,30s WS head sync; catch-up page100/256KiB,pass1000/1MiB,15min signed service-bound cursor. Eight critical slots/operation and100000 critical payload/reserved slots/acquirer; separate20000 task slots drop observations instead of blocking payment. Seven-day original-time event retention, explicit expiry intervals before deletion; metadata/business links retained separately, no silent native TTL financial deletion. Retention and SLO/cost numbers NOT individually owner-approved. Healthy commit-render p95<=4s/p99<=10s and retained bounded reconnect<=10s are proposed direct measurements, not proven AWS guarantees.
Service controls: one demo JWT principal without multiuser management and no issuer console. PROPOSED presenter-local loopback HTML/relay, viewed locally/screen-share, fixed synthetic environment/service business allowlist. Backend-only short-lived demo-user JWT and service IAM for WebSocket; no service secrets in HTML, no JWT removal. Origin/Host/CORS guard local relay; acquirer context never human identity. Remote/public anonymous hosting is not authorized. Actual service-token acquisition and authorizer/SigV4 support unresolved preflight; if unsupported construction blocked, never bypass auth.
