# Channel contract — PROPOSED v1
Not approved, implemented or tested. All interface choices are DESIGN ASSUMPTIONS; existing A business rules retain authority. Normative candidate companions: iso8583-profile.md and observation-contract.md.

## C1 — HTML JSON ingress
POST /console/v1/authorizations, HTTPS, application/json, UTF-8 restricted to ASCII values, body <=4096 bytes. JWT verified issuer/audience/expiry then active subject/context registry. No caller identity, decision, route, generation, actor, fault or arbitrary ISO input in browser body. Reject duplicate/unknown JSON keys, nulls, floats, coercion and non-ASCII references. Exactly these required fields:
contractVersion="1", operation="A", correlationId (1–64 profile alphabet), acquirerRef/merchantRef/terminalRef/paymentRef (1–128 profile alphabet), credentialFixtureRef (1–64), amount (string matching [0-9]{1,4}\.[0-9]{2}, value 1.00–9999.99), currency="USD", entryMode="simulated-contact" or "simulated-contactless", cvm="simulated-verified" or "simulated-not-required", cryptogramPresent (boolean).
Optional risk="pass" or "reject" (default pass), priorAuthorizationId (1–64).
No leading zero amount except zero itself, which fails domain minimum. Minor-unit conversion exact, no rounding. POS channel fixed by endpoint. Resolve all defaults/fixture permissions before idempotency equality. Reference validation precedes replay. Body maximum and aggregate DE48 limit both apply.
ACL assigns authorizationId/transactionId/attemptId/generation, durably stores exact wire instruction identity and aliases, then adapts request and validates response per P1–P4. 051/071 and VERIFIED/NOT_REQUIRED are synthetic representations, not actual EMV claims.

Response application/json <=4096 bytes: contractVersion, authorizationId (nullable before business admission), transactionId (same), attemptId, correlationId (this submission), originalCorrelationId (nullable until claim), outcome (APPROVED/DECLINED/PROCESSOR_REJECTED/NOT_CONFIRMED or null before admitted payment), disposition (COMPLETED/PENDING/REPLAY/REJECTED/NOT_DISPATCHED), businessVersion (integer or null), asOf (UTC RFC3339), observation (COMPLETE/PARTIAL/UNKNOWN), freshness (CURRENT/STALE), error (null or safe enumerated code).
No credentials, raw ISO, private result extension or issuer details. Authorized context-restricted console detail exposes sanitized processor actor/reason; issuer internal evidence requires separate diagnostic permission.

HTTP 200 for determined business response including decline/rejection/unknown/replay; 202 only in-flight duplicate without final evidence; 400 malformed/unsupported schema/profile; 401 authentication; 403 context; 404 inaccessible/unknown detail (same shape); 409 payload/prior conflict; 413 size; 415 media type; 503 durable admission/journal unavailable. 503 never instructs payment retry; client retrieves authorized history by attempt if admitted. Timeout/lost HTTP response is not proof of non-dispatch. Disable automatic HTTP/SDK retries of authorization. No retry-after on possible dispatch. Refresh/reconnect GET never initiates processing.

## C2 — private simulator byte boundary
ACL → simulator POST /internal/sim-iso87a/v1/authorizations over authenticated HTTPS, not public browser route. application/octet-stream, X-Simulator-Profile: SIM-ISO87A-v1; one complete body 1–2048 bytes, exact Content-Length after transport decoding. No compression, chunk semantics exposed to parser, newline framing or text/base64 on the logical interface. Responses HTTP 200 same profile/media type and exactly one 0110 <=2048 bytes. HTTP status is transport, never DE39.
Use API Gateway HTTP API payload v2 adapter if chosen: octet stream decoded from event body only when isBase64Encoded=true; reject invalid/noncanonical base64 or decoded size >2048; response body base64 with isBase64Encoded=true and octet-stream. Gateway wrapper is not ISO framing; public callers cannot submit wrapper flags as application data. Current direct Lambda synthetic JSON transport is a delta to replace at this seam, not already ISO-enabled.
Require authenticated service principal with route-specific permission and server context/fixture resolution; no trust in X headers for identity. Mutual TLS or IAM-controlled ingress realization remains human architecture/Security gate; candidate recommendation uses private API Gateway IAM-authorized HTTPS with SigV4 service identity. No new public function URL. Maximum Lambda/API envelope size comfortably exceeds 2048-byte decoded body.
Deadline 2 seconds from processor dispatch, inherited AWS A default; no automatic retries and no assumed harvesting of timed-out invocation. Empty/missing body/timeout/non-200/invalid 0110 after possible dispatch => unknown absent previously confirmed evidence. Authenticated explicit non-forwarding P4 rejection is different. Wrong media/profile or invalid bytes before simulator admission => safe HTTP 400/415, no issuer dispatch; ACL still cannot infer payment non-delivery from an untrusted transport error.
Separate approved internal evidence seam required for late replies; no public reconciliation endpoint or automatic worker commissioned.
