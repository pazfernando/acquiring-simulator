## State vocabulary

- **Specified:** approved behavior/criterion exists; no implementation claim.
- **Implemented:** code exists; mandatory checks may still be missing.
- **Developer-tested:** named checks passed for identified bytes/environment; not independent verification.
- **Integrated:** the actual cross-component application journey was executed.
- **Independently verified:** applicable QA/Security criteria passed for the identified artifact/environment.
- **Accepted:** Fernando explicitly accepted that verified outcome.
- **Blocked:** the exact dependency, owner and resume condition must be stated.
